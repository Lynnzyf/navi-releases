# Navi

macOS 屏幕角落里的 AI 小精灵。这个仓库只用来发布安装包。

**下载**：右边的 [Releases](https://github.com/Lynnzyf/navi-releases/releases/latest)，挑和自己芯片对应的 zip。有新版本时 Navi 会自己说。


## 1. 安装

1. 先看自己的 Mac 是什么芯片：左上角苹果菜单 →「关于本机」，写着 M1 / M2 / M3… 的用 `Navi-…-arm64-mac.zip`，写着 Intel 的用 `Navi-…-x64-mac.zip`。
   解压后把 `Navi.app` 拖进「应用程序」。
2. 第一次打开时，macOS 会提示"无法验证开发者"。这是因为这个 app 没有花钱做苹果签名，不是病毒。按下面任意一种办法打开：
   - 打开「系统设置 → 隐私与安全性」，拉到最下面，点 Navi 旁边的「仍要打开」。
   - 或者打开「终端」，粘贴这行后回车：`xattr -cr /Applications/Navi.app`，然后正常双击打开。
3. 打开后，屏幕右下角会出现一个青色的小球。Dock 里没有它的图标，这是正常的。

## 2. 填 API key（必须）

Navi 要调用一个大模型才能说话，你需要一个自己的 key。默认用硅基流动（SiliconFlow）上的 DeepSeek（的新用户免费额度）。

1. 在 https://cloud.siliconflow.cn 注册登录，进入「API 密钥」，新建一个密钥，复制下来（以 `sk-` 开头）。
2. 右键小球，点「打开配置文件夹」，用「文本编辑」打开 `api-key.env`。
3. 把 key 填在 `DEEPSEEK_API_KEY=` 后面（等号后面不要加空格或引号），保存。不用重启。

没填 key 时，跟它说话会显示"缺少 API key"。

## 3. 怎么用

- **单击**：打开或关闭输入框。按 Enter 发送，Shift+Enter 换行，按 Esc 关闭。
- **双击**：戳它一下。
- **拖动**：按住小球拖到你喜欢的位置，下次打开还在那里。
- **右键菜单**：
  - 「好」「烦」：对它刚才主动说的话打分。点「烦」之后，它会一段时间不再说同类的话。
  - 「勿扰 1 小时」
  - 「约定」：它答应过之后要提醒你的事情，可以在这里撤销。
  - 「状态」「打开配置文件夹」「退出」

你可以跟它约事情，比如"半小时后提醒我喝水""我要写两小时论文，别让我刷 B 站"。到时候它会自己冒出来（理论上）。

## 4. 权限

第一次用浏览器时，可能会弹出"Navi 想要控制 Safari / Chrome"，这是为了知道你在哪个网站。它只看域名，比如 `bilibili.com`，不看具体网页。允许或不允许都行，不允许它就不知道你在哪个网站。

## 5. 隐私

- 所有记录都只存在你自己的电脑上：`~/Library/Application Support/Navi/`。
- 发给模型的只有：当前时间、当前前台 app 名、网站域名、空闲时长、使用时长汇总，以及你跟它的对话。
- 它不记录你打了什么字。

## 6. 退出 / 卸载

- 退出：右键小球，点「退出」。
- 更新：退出 Navi，用新下载的 `Navi.app` 替换旧的，再像第一次一样右键 → 打开。你没改过的配置会自动换成新版；改过的会保留，新版放在旁边的 `xxx.new` 文件里，想要的话自己对照着改。
- 卸载：删掉 `Navi.app`，再删掉 `~/Library/Application Support/Navi/` 文件夹（在 Finder 里按 Cmd+Shift+G，粘贴这个路径就能找到）。

想改它的性格或参数，可以编辑配置文件夹里的 `prompts/persona.md` 和 `params.yaml`，保存后自动生效。
